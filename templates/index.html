    ระบบประเมินความเสี่ยง

    ประเมินความเสี่ยงเชิงพื้นที่ โดยวิเคราะห์ความสัมพันธ์ระหว่างปริมาณฟลูออไรด์ในน้ำและโรคฟันตกกระ
    หลักเกณฑ์การประเมินความเสี่ยง

    สมการทำนาย: อัตราฟันตกกระคาดการณ์ = α + β * (ปริมาณฟลูออไรด์เฉลี่ย ppm) + γ * (สัดส่วนผู้ป่วยรุนแรง)

    กำลังคำนวณค่าน้ำหนักสัมประสิทธิ์ทางสถิติ...
    ฟลูออไรด์ในน้ำ (ppm)
    β = 0.0000
    สัดส่วนเคสรุนแรง
    γ = 0.0000
    ค่าเริ่มต้น (Intercept)
    α = 0.0000
    ดัชนีความเสี่ยงทำนาย

    รายงานสอบสวนโรคฟันตกกระและประเมินผลกระทบฟลูออไรด์สูง

    ดาวน์โหลดแบบฟอร์มมาตรฐาน (แบบฟอร์ม 1 / แบบฟอร์ม 2 / แบบฟอร์ม 3 / Template ผลตรวจรายโรงเรียน), คู่มือระเบียบปฏิบัติ และบันทึกรายงานพร้อมแนบไฟล์ออนไลน์
    แหล่งน้ำ / พื้นที่ .docx
    แบบฟอร์ม 1: การประเมินผลกระทบฟลูออไรด์สูง

    ประเมินความเสี่ยงแหล่งน้ำต้นเหตุ (ฟลูออไรด์ ≥ 4 ppm), กลุ่มประชากรเสี่ยงในพื้นที่ (สพด., โรงเรียน, หญิงตั้งครรภ์) และแนวทางจัดการ

    ดาวน์โหลดแบบฟอร์ม 1 (.docx)
    รายบุคคล / ทันตกรรม .docx
    แบบฟอร์ม 2: การสอบสวนสาเหตุฟันตกกระ

    สอบสวนรายบุคคล, ประวัติการบริโภคน้ำดื่มย้อนหลัง, การตรวจประเมินผิวฟัน และจำแนกระดับความรุนแรงตาม Dean's Index (0-5)

    ดาวน์โหลดแบบฟอร์ม 2 (.docx)
    มาตรการ / จัดการปัญหา .docx
    แบบฟอร์ม 3: แนวทางการจัดการฟันตกกระ

    มาตรการระดับบุคคล (ระดับ 4 ขึ้นไป) และครัวเรือน (เด็ก 0-8 ปี), เปลี่ยนแหล่งน้ำ, อุดหนุนน้ำบริโภคสะอาด และติดตามประเมินซ้ำ 12 เดือน

    ดาวน์โหลดแบบฟอร์ม 3 (.docx)
    คัดกรอง / รายโรงเรียน .xlsx
    Template ผลตรวจฟันตกกระแยกรายโรงเรียน

    ไฟล์แบบบันทึกผลการคัดกรองฟันตกกระนักเรียนรายโรงเรียน พร้อมตารางสรุปจำนวนตรวจและระดับ Dean's Index (ระดับ 1-5)

    ดาวน์โหลด Template โรงเรียน (.xlsx)
